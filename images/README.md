Add your image files here with these exact names so the site picks them up automatically:

- `cover.jpg` — the full-width cover/hero image on the homepage
- `portrait.jpg` — your photo used in the "About Me" section
- `logo.png` — small logo shown top-left of the nav on every page (linked to the homepage). Use a transparent PNG, roughly square or wide, ~100–150px tall so it scales down cleanly to the 42px display height.
- `field-photo.jpg` — wide photo banner shown between "Research Themes and Projects" and "Publications" on the homepage. A landscape-orientation photo works best since it's cropped to a short, wide strip.

Any image format works (jpg, png, webp) as long as you update the filename referenced in `index.html` / `css/style.css` to match.
